# Name Duel

Static site, no build step.

1. Create a GitHub repository and upload everything in this folder (index.html, support.js, uploads/, README.md).
2. Settings > Pages > Source: "Deploy from a branch", branch main, folder / (root).
3. Open https://<your-username>.github.io/<repo-name>/

Notes
- Meg's and Cathleen's data is saved in each browser's localStorage, so it stays on the device they use.
- The starter list loads from uploads/Name_List.xlsx the first time. You can re-import any XLSX/CSV in the app.
- The "Fill in details" button only works inside the design tool; on GitHub Pages, type details manually.
- Open via the Pages URL or a local server, not by double-clicking index.html (the starter list is fetched).
